-blog

个人作品与创作模板

这是基于 Next.js 的个人网站模板，包含前台展示、后台管理与作品售卖功能。当前为 GitHub Pages 的临时静态首页展示。

快速介绍

适合设计师与创作者的个人网站模板，支持文章、作品与教程展示，并集成后台管理与 AI 辅助功能。

特点

  • 前台与后台一体化，基于 Next.js App Router
  • 多语言支持（中文 / 英文）
  • 作品展示、购买流程与 AI 内容助手（生产环境需后端支持）

技术栈

  • Next.js 16, React 19, TypeScript
  • Tailwind CSS, Prisma

说明

此页面为临时静态首页。若要恢复完整功能，请部署到支持 Node 的平台（例如 Vercel），或配置 CI 预渲染动态页面后发布到 Pages。

操作

  • 查看仓库： https://github.com/Zyx7732/-blog
  • 后台（需登录）： /admin （在完整部署时可用）
提示 若你要让 Pages 直接显示此页面，请在仓库 Settings → Pages 中把 Source 设为 main / docs。生效后访问： https://Zyx7732.github.io/-blog/
